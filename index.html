Water Level Automation Using Mobile IoT

NodeMCU ESP8266 • Ultrasonic Sensor • Blynk IoT • SIM800L • OLED Display

College: Govt I.T.I. Solapur | Trade: COPA | Project Guide: V. D. Bhange & A. T. Maskare

1. Introduction

In today’s digital era, automation plays an important role in saving time, water and electricity. Many homes and institutions face problems like water tank overflow or running the motor when the tank is empty. This project “Water Level Automation Using Mobile IoT” automatically controls the water pump based on the water level in the tank. Using an ultrasonic sensor and IoT technology, the system monitors the water level and automatically turns the motor ON when the water level is low and OFF when the tank becomes full. Users can also monitor the tank level and control the motor remotely using a mobile application from anywhere in the world.

2. Objectives

  • Automate the water tank filling process
  • Prevent water overflow and wastage
  • Reduce manual effort of switching motor ON/OFF
  • Allow remote monitoring through mobile application
  • Provide real-time alerts and notifications
  • Improve efficient water management using IoT

3. Need of Project

  • Water tanks often overflow due to human negligence
  • Manual monitoring of tank level is inconvenient
  • Electricity is wasted if motor runs unnecessarily
  • Smart monitoring is needed in homes and institutions
  • IoT enables remote monitoring and automation

4. Technologies Used

  • Microcontroller: NodeMCU ESP8266
  • Sensor: Ultrasonic Sensor
  • Communication: WiFi / SIM800L GSM
  • Display: 0.96" OLED Display
  • Mobile Platform: Blynk IoT App
  • Programming: Arduino IDE
  • Cloud Platform: Blynk Cloud

5. Working Principle

  • The ultrasonic sensor continuously measures water level.
  • NodeMCU processes the sensor data.
  • When water level becomes LOW, the motor automatically turns ON.
  • When the tank becomes FULL, the motor automatically turns OFF.
  • Water level data is sent to the Blynk mobile app via WiFi or GSM.
  • Users can monitor tank level and control motor remotely.

6. Advantages

  • 24×7 automatic water monitoring
  • Prevents water overflow and wastage
  • Saves electricity and water
  • Remote motor control from anywhere
  • Real-time notifications
  • Reduces human effort

7. Conclusion

The Water Level Automation Using Mobile IoT system provides a smart and efficient solution for water management. By using sensors, NodeMCU microcontroller, IoT cloud and mobile connectivity, the system automatically controls the water pump and allows users to monitor the tank remotely. This project helps in saving water, electricity and time, making it a useful solution for homes, industries and institutions.
